✦ System 02

Vision-Grounded Self-Healing Web Scraper

Layer 1 - CACHED FAST PATH

SQLite locator cache stores verified CSS selectors. On each run, the fast path attempts cached selectors with a 14ms timeout. If the element resolves, extraction proceeds at native speed.

Layer 2 - MUTATION DETECTION

When cached selectors fail (DOM redesign, class name rotation, dynamic rendering), the system captures a full-page screenshot and forwards it to the vision pipeline.

Layer 3 - GEMINI VISION SPATIAL FALLBACK

Gemini Vision API receives the screenshot with the target element description. Returns bounding-box coordinates. The system maps coordinates back to DOM elements, extracts the data, and writes the new working selector back to the SQLite cache.
