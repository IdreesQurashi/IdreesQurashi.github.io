Autonomous Lead Intelligence Swarm

6-agent DAG · LangGraph runtime · Redis state bus

 DEPLOYED

A six-agent supervisor swarm that autonomously executes full-cycle B2B lead generation. The Supervisor Agent decomposes the ICP brief into parallel scraping tasks. Vision Scraper agents extract LinkedIn and Apollo data with self-healing selector recovery. An Enrichment Agent cross-references company data via Hunter.io and Clearbit. A Personalization Agent invokes Gemini Flash to generate bespoke email copy per contact. The Delivery Agent dispatches via Gmail API with randomized pacing and logs every send to a deduplication registry.

design.decisions

State management

All agent outputs written to a shared TypedDict state. Redis Streams used as cross-process memory bus for parallel sub-agent coordination.

Failure recovery

Conditional edges route to ErrorHandler on tool_call exceptions. Exponential backoff with jitter. Max 3 retries before abort and Telegram alert.

Vision grounding

On selector failure, Playwright captures a full-page screenshot. GPT-4o Vision annotates bounding boxes. New XPath generated and injected in real time.

Rate guard

Delivery agent enforces randomized 900s to 1800s sleep between sends. Stateful dedup log prevents replay on crash recovery.

Code Generation & Audit Agent

3-agent loop · sandboxed execution · diff-aware review

Iterates until all tests pass or 5 rounds are exhausted. Generates complete production scripts with zero placeholder code.
