stage.breakdown

Seven deterministic stages

01

ICP Definition & Scraper Dispatch

icp_scraper

Supervisor agent parses ICP brief JSON (industry, headcount, title, geography). Dispatches Apollo API batch query and LinkedIn Playwright scraper in parallel. Merges results and normalises schema.

420
contacts/run
02

Email Verification & Enrichment

hunter_verifyclearbit

Hunter.io SMTP verification for each raw email. Clearbit enriches company domain with tech stack, funding round, and headcount. Contacts with confidence below 0.75 are silently discarded. Zero guessed addresses.

<0.25%
bounce target
03

Deduplication Registry Check

dedup_registrySQLite

Stateful sent-log registry backed by SQLite. Each contact email is SHA-256 hashed and checked before enqueueing. Survives daemon restarts. Eliminates duplicate sends across pipeline reruns.

0
duplicate sends
04

Gemini Flash Personalization Engine

gemini-flash-lite

Six-key rotating Gemini Flash Lite pool generates bespoke email copy per contact. System prompt encodes ICP context, company enrichment data, and tone rules. Outputs structured JSON with subject, body, and PS line. Rotates keys to avoid quota limits.

294
drafts/run
05

Rate Guard & Human-Pacing Daemon

rate_guard

Background daemon enforces randomized 900s to 1800s sleep between individual sends. Mimics human send patterns to prevent Google Workspace abuse flags. Sub-minute burst sending is architecturally impossible by design.

15-30m
send interval
06

Gmail API Dispatch

gmail_apiOAuth2

Authenticated Gmail API sends with OAuth2 refresh token management. Each send is logged to the dedup registry with timestamp and message ID. Hard bounce detection triggers immediate 24-hour cooldown and domain blacklisting.
